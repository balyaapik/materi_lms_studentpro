Pola Bilangan dan Barisan

Mengenali pola, menentukan suku berikutnya, membedakan barisan aritmetika dan geometri, serta memahami notasi suku ke-n.

Daftar isi: konsep · jenis pola · suku ke-n · simulasi · latihan

1. Apa Itu Pola dan Barisan?

Pola bilangan adalah aturan tertentu yang menghubungkan satu bilangan dengan bilangan berikutnya. Jika bilangan-bilangan itu ditulis berurutan, kita memperoleh barisan.

U₁, U₂, U₃, …, Uₙ

Simbol Uₙ berarti suku ke-n. Contoh: pada barisan 3, 6, 9, 12, … maka U₁=3, U₂=6, U₃=9.

2. Jenis Pola yang Sering Muncul

Aritmetika
Selisih antarsuku tetap.
Contoh: 5, 8, 11, 14, …
Selisih = +3.
Geometri
Perbandingan antarsuku tetap.
Contoh: 2, 6, 18, 54, …
Rasio = ×3.
Bilangan ganjil
1, 3, 5, 7, 9, …
Bilangan persegi
1, 4, 9, 16, 25, … = 1²,2²,3²,4²,5²,…
Strategi: cek dulu selisih. Jika tidak tetap, cek rasio. Jika keduanya tidak tetap, cari pola lain seperti kuadrat, selang-seling, atau kombinasi beberapa aturan.

3. Menentukan Suku ke-n

Untuk pola sederhana, rumus suku ke-n dapat ditebak dari hubungan antara posisi n dan nilai suku.

Contoh: 2, 4, 6, 8, …
Setiap suku adalah 2 kali nomor urutnya, sehingga Uₙ = 2n. Maka U₂₀ = 2×20 = 40.
Contoh: 1, 4, 9, 16, …
Ini adalah bilangan persegi, sehingga Uₙ=n². Maka U₁₀=100.

4. Simulasi Pendeteksi Pola

Masukkan empat suku awal dipisahkan koma. Program akan mencoba mendeteksi apakah polanya aritmetika atau geometri.

5. Contoh Soal

Soal: Tentukan tiga suku berikutnya dari 7, 11, 15, 19, …
Pembahasan: Selisih setiap suku adalah +4. Jadi suku berikutnya 23, 27, dan 31.
Soal: Tentukan suku berikutnya dari 2, 6, 18, 54, …
Pembahasan: Tiap suku dikali 3, sehingga suku berikutnya 162.

6. Latihan

1. Suku berikutnya dari 4, 9, 14, 19, … adalah ...
24. Selisihnya selalu +5.
2. Suku berikutnya dari 3, 12, 48, 192, … adalah ...
768. Setiap suku dikali 4.
3. Jika Uₙ=n²+1, tentukan U₅.
26. U₅=5²+1=26.
