Kontinuitas: Definisi dan Analisis Grafik

Matematika SMA/UTBK · Limit dan Kontinuitas · Materi 6

Sebuah fungsi kontinu di \(x=a\) jika limit dua sisinya ada dan nilai limit sama dengan nilai fungsi.

1. Syarat Kontinuitas

\[\lim_{x\to a^-}f(x)=\lim_{x\to a^+}f(x)=f(a)\]
Limit kiri

Harus ada.

Limit kanan

Harus sama dengan limit kiri.

Nilai fungsi

Harus sama dengan nilai limit.

2. Membaca Kontinuitas dari Grafik

Pada titik berlubang, limit bisa ada tetapi nilai fungsi berbeda atau tidak terdefinisi. Pada titik loncatan, limit kiri dan kanan berbeda sehingga limit dua sisi tidak ada.

3. Kapan Kontinuitas Gagal?

KondisiKesimpulan
Limit kiri ≠ limit kananLimit dua sisi tidak ada
Limit ada tetapi f(a) tidak terdefinisiTidak kontinu
Limit ada tetapi limit ≠ f(a)Tidak kontinu

4. Interval Kontinuitas

Setelah titik diskontinu ditemukan dari grafik, garis bilangan dibagi menjadi interval yang tidak melewati titik-titik tersebut.

Jika fungsi hanya tidak kontinu di x=2 dan x=5, maka interval kontinuitasnya adalah \(( -\infty,2)\cup(2,5)\cup(5,\infty)\).

5. Cek Pemahaman

1. Fungsi kontinu di x=a jika ....

A. hanya f(a) ada
B. hanya limit kiri ada
C. limit kiri = limit kanan = f(a)
D. f(a)=0
E. grafik garis lurus
ANSWER: C
EXPLANATION: Itulah syarat kontinuitas di satu titik.

2. Limit dua sisi bernilai 4 tetapi f(a)=7. Fungsi di a ....

A. kontinu
B. tidak kontinu
C. konstan
D. meningkat
E. pasti kuadrat
ANSWER: B
EXPLANATION: Nilai limit tidak sama dengan nilai fungsi.
