Limit Bentuk Tak Tentu 0/0

Matematika SMA/UTBK · Limit dan Kontinuitas · Materi 4

Inti materi
Jika substitusi langsung pada pecahan menghasilkan bentuk \(\frac00\), kita menghadapi bentuk tak tentu. Pada bentuk aljabar yang dapat difaktorkan, keluarkan faktor penyebab nol lalu sederhanakan sebelum mengambil limit.

1. Apa Arti Bentuk 0/0?

Contoh:

\[\lim_{x\to2}\frac{x^2-4}{x-2}\]

Substitusi langsung memberi \(\frac00\). Ini bukan jawaban akhir, melainkan tanda bahwa ekspresi perlu disederhanakan.

2. Faktorkan dan Sederhanakan

\[x^2-4=(x-2)(x+2)\]\[\frac{x^2-4}{x-2}=x+2\quad(x\ne2)\]
\[\lim_{x\to2}\frac{x^2-4}{x-2}=4\]

3. Makna Grafik: Titik Berlubang

Fungsi asli tidak terdefinisi di x=2, tetapi setelah penyederhanaan grafik mengikuti garis \(y=x+2\) dengan lubang di \((2,4)\). Limit tetap 4.

4. Pola Faktorisasi

\[a^2-b^2=(a-b)(a+b)\]
\[x^2+(p+q)x+pq=(x+p)(x+q)\]
\[\lim_{x\to3}\frac{x^2-9}{x-3}=6\]
\[\lim_{x\to1}\frac{x^3-x^2+x-1}{x-1}=2\]

5. Soal Parameter

Jika soal menyatakan substitusi menghasilkan bentuk \(0/0\), gunakan syarat bahwa pembilang dan penyebut sama-sama nol di titik tujuan untuk menentukan parameter.

6. Cek Pemahaman

1. Nilai \(\lim_{x\to5}\frac{x^2-25}{x-5}\) adalah ....

A. 0
B. 5
C. 10
D. 25
E. tidak ada
ANSWER: C
EXPLANATION: Faktorkan menjadi (x-5)(x+5), lalu limit x+5 adalah 10.

2. Bentuk \(0/0\) berarti ....

A. limit selalu 0
B. limit pasti tidak ada
C. perlu penyederhanaan
D. penyebut diabaikan
E. pembilang diabaikan
ANSWER: C
EXPLANATION: 0/0 adalah bentuk tak tentu.
