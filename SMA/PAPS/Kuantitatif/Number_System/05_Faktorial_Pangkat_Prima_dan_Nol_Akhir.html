Faktorial, Pangkat Prima, dan Nol Akhir

Menghitung faktor prima dalam faktorial tanpa menuliskan bilangan raksasa.

1. Faktorial

Untuk bilangan bulat positif n:

n! = n(n−1)(n−2)...3·2·1, dan 0! = 1

2. Pangkat Prima dalam n!

Pangkat tertinggi prima p yang membagi n! adalah:

vₚ(n!)=⌊n/p⌋+⌊n/p²⌋+⌊n/p³⌋+...
Contoh: v₅(100!)=20+4=24.

3. Nol di Ujung Faktorial

Satu nol berasal dari faktor 10=2×5. Dalam n!, faktor 2 lebih banyak, jadi jumlah nol akhir ditentukan oleh banyak faktor 5.

Nol akhir 100! = ⌊100/5⌋+⌊100/25⌋ = 24.

4. Pangkat Bilangan Komposit

Jika ingin mencari pangkat tertinggi 12 yang membagi n!, faktorkan 12=2²×3. Maka:

v₁₂(n!) = min(⌊v₂(n!)/2⌋, v₃(n!))

5. Pecahan Faktorial

Untuk n!/k!, kurangi eksponen faktor prima:

vₚ(n!/k!) = vₚ(n!) − vₚ(k!)

6. Banyak Faktor Positif

Jika N=p₁^a·p₂^b·p₃^c, banyak faktor positifnya adalah:

(a+1)(b+1)(c+1)
Untuk N=2⁴·3²·5³, banyak faktor=5×3×4=60.

7. Strategi HOTS

  1. Faktorkan target lebih dahulu.
  2. Untuk nol akhir, cari pasangan 2 dan 5.
  3. Untuk pangkat komposit, bandingkan kebutuhan tiap prima.
  4. Gunakan fungsi lantai untuk menghitung kelipatan p, p², p³, dan seterusnya.
Tip: jangan menghitung n! secara eksplisit. Hampir semua soal PAPS faktorial dapat diselesaikan lewat eksponen faktor prima.
