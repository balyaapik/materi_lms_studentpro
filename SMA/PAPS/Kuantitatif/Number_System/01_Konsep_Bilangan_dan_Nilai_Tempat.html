Konsep Bilangan dan Nilai Tempat

Fondasi membaca digit, membentuk bilangan, dan memodelkan informasi posisi.

1. Digit dan Bilangan

Sistem desimal memakai digit 0–9. Nilai sebuah digit bergantung pada posisinya. Pada 507.326, digit 7 bernilai 7.000 sedangkan digit 3 bernilai 300.

2. Nilai Muka dan Nilai Tempat

3. Model Aljabar Digit

Bilangan tiga digit dengan digit ratusan a, puluhan b, dan satuan c dapat ditulis:

100a + 10b + c

Bilangan terbaliknya adalah 100c + 10b + a. Model ini sangat berguna untuk soal pertukaran digit, jumlah digit, selisih bilangan, dan digit hilang.

4. Membentuk Bilangan Maksimum/Minimum

Untuk maksimum, susun digit dari terbesar ke terkecil. Untuk minimum, digit pertama tidak boleh 0. Jika tersedia 0, pilih digit bukan nol terkecil sebagai digit pertama, kemudian letakkan 0 sesudahnya.

Contoh: dari 0,2,4,7 bilangan empat digit terkecil adalah 2047, bukan 0247.

5. Bilangan Berulang

Jika ab adalah bilangan dua digit, maka:

abab = 100(ab) + ab = 101(ab)

Untuk blok tiga digit:

abcabc = 1000(abc) + abc = 1001(abc)

Karena 1001=7×11×13, semua bilangan bentuk abcabc pasti habis dibagi 7, 11, dan 13.

6. Strategi HOTS

  1. Terjemahkan posisi digit menjadi bentuk aljabar.
  2. Gunakan batas digit 0–9 dan digit pertama ≠0.
  3. Gabungkan dengan syarat paritas/keterbagian.
  4. Untuk maksimum/minimum, sempitkan kandidat sebelum mencoba.
