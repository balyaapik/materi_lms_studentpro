Digit Satuan, Pola Bilangan, dan Strategi HOTS

Menangani pangkat besar, digit akhir, blok berulang, dan perhitungan banyak bilangan.

1. Siklus Digit Satuan

Digit 0,1,5,6 tetap sama untuk semua pangkat positif.

2. Pangkat Besar

Untuk satuan 7153, hitung 153 mod 4 = 1. Ambil elemen pertama siklus 7, yaitu 7.

3. Dua Digit Terakhir

Gunakan modulo 100. Ambil sisa setiap tahap agar bilangan tidak membesar. Untuk basis yang relatif prima dengan 100, pola pangkat dapat dipercepat dengan sifat periodik.

4. Bilangan Berulang

Karena 1001=7×11×13, bilangan seperti 325325=325×1001 otomatis habis dibagi 7,11,13.

5. Menghitung Banyak Kelipatan

Banyak kelipatan d pada [L,U] = ⌊U/d⌋ − ⌊(L−1)/d⌋

Untuk “habis dibagi A tetapi tidak B”, hitung kelipatan A lalu kurangi yang juga kelipatan KPK(A,B).

6. Menghitung Kemunculan Digit

Pecah per posisi: ratusan, puluhan, satuan. Pada blok lengkap, setiap digit muncul teratur. Hindari menulis seluruh bilangan satu per satu.

7. Hierarki Strategi PAPS

  1. Kenali struktur: digit, keterbagian, sisa, pangkat, faktorial.
  2. Pilih alat: nilai tempat, modulo, identitas, faktorisasi prima.
  3. Kecilkan bilangan: pertahankan hanya informasi relevan.
  4. Eliminasi opsi: paritas, digit akhir, orde besaran.
  5. Verifikasi: masukkan kandidat ke syarat awal.
Untuk HOTS: satu soal sering menggabungkan beberapa konsep sekaligus, misalnya digit hilang + keterbagian + maksimum/minimum atau pangkat + modulo + pola siklus.
